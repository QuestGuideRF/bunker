# Бункер

Браузерная многопользовательская игра по мотивам настольной игры «Бункер». Игроки получают случайные карточки персонажей с характеристиками (профессия, здоровье, фобия, багаж и т.д.), по очереди раскрывают часть характеристик, обсуждают в чате и голосуют за исключение из бункера. Цель — остаться среди выживших до заполнения ограниченного числа мест.

## Технологии

- **Бэкенд:** PHP 8+, MySQL 8 (без фреймворков)
- **Фронтенд:** ванильный JavaScript, HTML5, CSS3
- **Обновление данных:** polling, подходит для простого хостинга reg.ru
- **Сессии:** PHP-сессии, cookie на 3 месяца для «запомнить меня»

## Меню и разделы

- **Профиль** — аватар (можно загрузить фото), никнейм, статистика (игры, победы, % побед), переключатель тёмной/светлой темы, выход.
- **Открытые** — список публичных комнат без пароля. По клику — вход в комнату по коду.
- **Приватные** — вход в комнаты с паролем: форма «Код комнаты» + «Пароль». Ниже — список «Мои комнаты» (комнаты, в которых вы уже участвуете), по клику — переход в комнату.
- **Создать** — создание новой комнаты: название, макс. игроков, мест в бункере, время обсуждения и голосования, публичная/приватная (при приватной — пароль).

## Как проходит игра

1. **Лобби** — в комнате видны код комнаты, список игроков. Создатель может кикнуть игрока, начать игру (нужно минимум 2 человека).
2. **Карточки** — каждый видит только свою полную карточку (все характеристики). Нужно нажать «Я готов»; когда все готовы — переход к раскрытию.
3. **Раскрытие** — каждый выбирает, какую характеристику показать остальным (в рамках лимита за раунд), нажимает «Раскрыть выбранное». После раскрытий — обсуждение.
4. **Обсуждение** — таймер до голосования, доступен чат. Создатель может досрочно перевести в голосование.
5. **Голосование** — каждый выбирает одного игрока для исключения. По итогам один выбывает; если выживших ≤ мест в бункере — игра завершена, иначе — следующий раунд (снова раскрытие).
6. **Завершение** — список выживших и раскрытые карточки. Создатель может начать «Новую игру», все могут выйти «На главную».

Комната сохраняется в браузере (localStorage): при перезагрузке страницы вы остаётесь в той же комнате, если вас не выгнали.

## Настройка конфигурации

Скопируйте [шаблон окружения](.env.example) в `.env` и заполните поля для базы данных, приложения и WebSocket.

Перед запуском создайте локальный файл `.env` на основе шаблона `.env.example`.

1. Скопируйте `.env.example` в `.env`.
2. Заполните параметры подключения к MySQL.
3. Проверьте `APP_URL`, `WS_URL`, `WS_HOST` и `WS_PORT` под ваш домен и способ запуска.
4. Не коммитьте `.env` в репозиторий.

Минимально нужно заполнить:

- `DB_HOST`
- `DB_NAME`
- `DB_USER`
- `DB_PASS`
- `APP_URL`
- `WS_URL`

Пример:

```env
DB_HOST=localhost
DB_NAME=change_me
DB_USER=change_me
DB_PASS=change_me
APP_URL=https://example.com
WS_URL=wss://example.com/ws
```
